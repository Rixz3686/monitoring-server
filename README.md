# 🚀 NMM App

> **Modern, Minimalist, and Real-Time Server Monitoring Dashboard**

NMM App adalah aplikasi pemantauan peladen (*server monitoring*) *full-stack* yang dirancang dengan antarmuka super bersih (*clean UI*), aksen warna pink elegan, dan performa *backend* yang secepat kilat. Pantau status layanan, *website*, dan infrastruktur jaringanmu dalam satu layar yang memanjakan mata.

---

## ✨ Fitur Unggulan

- 🎨 **Clean & Minimalist UI:** Antarmuka bergaya *frosted glass* dan tata letak *borderless* yang tidak membuat mata lelah.
- ⚡ **Real-Time Latency:** Pantau waktu respons (*ping/latency*) peladen secara *real-time* dalam satuan milidetik (ms).
- 🌐 **Multi-Protocol Support:**
  - **HTTP/HTTPS:** Deteksi otomatis status *website* dan layanan web.
  - **TCP:** Ketuk *port* spesifik untuk layanan seperti *database* atau SSH.
  - **ICMP (Ping):** Pengecekan paket dasar untuk stabilitas peladen.
- 👥 **Team Management:** Kelompokkan target pemantauan ke dalam ruang kerja (Tim) yang terisolasi.
- 🐳 **Docker Ready:** Langsung berlayar ke *server production* hanya dengan satu perintah.
- 📨 **Notifications:** Mengirimkan notif real-time keadaan server ke berbagai aplikasi. 

---

## 🛠️ Tech Stack

Aplikasi ini dibangun menggunakan teknologi modern untuk menjamin kecepatan dan kemudahan pengembangan:

- **Frontend:** React.js, TypeScript, Vite, Material UI (MUI).
- **Backend:** Bun 🦊, Elysia.js, SQLite.
- **Infrastructure:** Docker & Docker Compose.
